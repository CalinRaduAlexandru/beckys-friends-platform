# Workflow pentru activitățile părinților

## Sursa unică

`docs/parent-experiences-source.md` este registrul editorial canonic. Nu mai folosim lista brută separat și nu copiem idei între secțiuni.

## Stările unei idei

- `De trecut`: ideea nu a fost încă testată sau discutată cu Radu.
- `Păstrate`: ideea a fost acceptată; dacă a fost redenumită sau rescrisă, aici apare doar forma finală.
- `Nefolosite`: ideea a fost respinsă sau scoasă; se notează motivul când este cunoscut.

## Regula de lucru

La fiecare feedback explicit:

1. modificăm activitatea din `data/parent-experiences.json`, dacă este deja în aplicație;
2. mutăm ideea în secțiunea corectă din `docs/parent-experiences-source.md`;
3. păstrăm o singură formulare finală și eliminăm varianta veche din „De trecut”;
4. dacă este scoasă, o mutăm la „Nefolosite”, nu o ștergem;
5. înainte de o sugestie nouă, căutăm în „Păstrate” și „Nefolosite” ca să nu repetăm o idee respinsă sau deja parcursă.

## Ce înseamnă „am trecut prin toată lista”

Înseamnă că secțiunea „De trecut” este goală. Abia atunci putem propune reluarea ideilor din „Păstrate”, într-o ordine nouă și cu acord explicit.
